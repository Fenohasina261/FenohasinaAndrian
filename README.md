# Portfolio Professionnel — Fenohasina Ratsitoarivonjy

Portfolio personnel de style éditorial fusionnant la **création de contenu / UGC**, la **gestion des médias sociaux** et le **marketing numérique**. Ce projet a été conçu pour présenter de manière fluide des compétences techniques et créatives à travers une identité visuelle premium.

## 🛠️ Stack Technique
* **HTML5 & CSS3** (Vanilla, sans framework lourd)
* **JavaScript** (Vanilla : navigation mobile, défilement fluide, effets 3D au survol, observateurs d'intersection pour les animations)
* **Chart.js** (Intégré via CDN pour les graphiques analytiques des études de cas en marketing digital)
* **Hébergement & Déploiement** : Netlify (avec formulaire de contact géré via FormSubmit)
